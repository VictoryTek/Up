## What's Changed

### Bug Fixes
- **Update All re-disables when nothing is left to update**: After an update run completes, the button returns to its greyed-out state instead of staying clickable. A backend that updated cleanly now reports zero pending updates; the button only stays active if an un-skipped source still has outstanding updates (for example one that errored out).
- **Progress bar no longer shifts the layout**: The update progress bar now reserves its space permanently and fades in on start rather than being inserted into the layout. Pressing "Update All" no longer pushes the page down and introduces a vertical scroll bar.

### Improvements
- **Clear "update complete" indication**: When an Update All run finishes, a banner appears below the header — green "System is up to date" on success, or "Update finished with errors — see the log below" when a source failed. It clears automatically when the next check or update starts.

### Internal
- `UpdateRow::set_status_success` records a zero available-count so the window can re-gate the Update All button from row state without re-running the availability check.
