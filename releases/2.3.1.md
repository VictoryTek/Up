## What's Changed

### Fixes
- **True progress bar**: The progress bar now advances in step with the updates actually being installed. Previously it moved only once per update source — jumping partway across when a source started, then freezing for the entire install before shooting to the end — so a run dominated by one long source (a NixOS rebuild, a large Flatpak batch) showed a bar stuck near the start the whole time.

### Improvements
- **Per-source progress signals**: Progress is now read from each package manager's own output as it runs — Nix derivation and fetch plans, Flatpak transaction counters, APT unpack/configure steps, and the `n/m` counters from DNF, Pacman and Zypper. Homebrew, fwupd and plugin backends report progress too.
- **No misleading motion**: The bar never moves backwards, and a source whose output cannot be parsed simply shows no fine-grained progress rather than an invented position.
